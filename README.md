# Prompt Commander

Prompt Commander is an AI prompt engineering terminal for building, managing, and optimizing prompts using popular context frameworks. It features a terminal-inspired UI, live preview, context usage tracking, and template management.

![Prompt Commander Screenshot](sora1.webp)

## Features

- **Framework Selector:** Choose from Addy's 10-Part, COSTAR, CRISPE, RTF, and BAB frameworks for structured prompt engineering.
- **Context Patterns:** Select context usage patterns (Write, Select, Compress, Isolate) to optimize prompt context.
- **Model Selector:** Target different AI models (GPT-4, Claude, GPT-3.5) and see live context usage stats.
- **Prompt Builder:** Fill out framework sections with guidance, collapse/expand, and auto-save drafts.
- **Live Preview:** See your prompt as you build it, with syntax highlighting and easy copy/export.
- **Best Practices Sidebar:** Get prompt engineering best practices and keyboard shortcuts.
- **Template Management:** Save, load, and manage prompt templates with descriptions.
- **Responsive Design:** Works on desktop and mobile, with light/dark mode support.

## Getting Started

1. **Clone or Download** this repository.
2. **Open `index.html`** in your browser. No build step required.
3. **Start building prompts** using the UI controls and framework sections.

## Project Structure

- `index.html` – Main HTML file and UI layout
- `app.js` – Application logic and framework definitions
- `style.css` – Modern terminal-inspired styles (light/dark mode)
- `sora1.webp`, `sora2.webp` – Demo images/screenshots
